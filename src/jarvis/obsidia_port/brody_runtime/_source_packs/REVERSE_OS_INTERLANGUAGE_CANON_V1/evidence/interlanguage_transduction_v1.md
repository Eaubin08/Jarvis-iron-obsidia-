## Définition

Reverse OS n'est pas un simple traducteur d'entrée.

Reverse OS est une couche bidirectionnelle / multidirectionnelle d'interlangage :

Humain ↔ Chinois/glyphe ↔ Géométrie ↔ Math ↔ Code ↔ IR ↔ Kernel-readable ↔ Sortie adaptée.

## Source de vérité

La source de vérité n'est jamais :
- le chinois,
- le français,
- l'anglais,
- la géométrie,
- le totem,
- le symbole,
- la narration.

La source de vérité est :

IR_L2 + CONTRAT_COGNITIF_L2_5.

## Rôle du chinois

Le chinois / hanzi est une projection compacte de rapidité cognitive.

Il sert à :
- compresser un concept,
- accélérer la navigation symbolique,
- créer des glyphes combinables,
- servir de code mnémotechnique.

Il ne sert pas à :
- décider,
- prouver,
- muter le kernel,
- remplacer l'IR,
- devenir source de vérité.

## Rôle de la langue native utilisateur

Toute projection symbolique doit avoir son reverse natif :

hanzi → français
hanzi → anglais
hanzi → math
hanzi → IR
hanzi → explication audience

Aucun glyphe n'est accepté s'il ne peut pas être reprojeté.
